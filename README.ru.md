# Claude Code TUI

[English README](README.md) · [Архитектура](docs/architecture.md) ·
[Участие](CONTRIBUTING.md) · [Безопасность](SECURITY.md) · [Changelog](CHANGELOG.md) ·
[Сопровождение](docs/maintenance.md)

Локальное терминальное рабочее пространство для **Claude Code CLI**: проекты и
чаты слева, открытые сессии, диалог и Markdown-заметки в Neovim.

Проект находится в ранней разработке. Поддерживается Linux; интерфейс сейчас
на русском языке. Это независимый проект, не продукт Anthropic. Claude
запускается именно через установленный CLI с его авторизацией и разрешениями.

## Возможности

- Сворачиваемые проекты, поиск, закрепление и переименование чатов.
- Обновление названий после `/rename` во всех панелях, включая открытые сессии.
- Переключение между несколькими работающими Claude PTY без остановки других.
- Новый чат с выбором известной папки или браузером каталогов от `$HOME`.
- Заметка в Neovim под чатом; отдельный Markdown-документ в базе знаний.
- Выделение мышью построчно только внутри чата; копирование при отпускании.
- Просмотр только вывода активного Claude в Neovim.
- Палитра терминала, мышь, русские и английские клавиатурные сочетания.
- Статусы CLI, непрочитанные фоновые ответы и включаемые уведомления.
- Быстрый переключатель, предыдущий чат, палитра команд и общая справка.
- Поиск текста сообщений и Markdown, каталог заметок, выделение в заметку.
- Перетаскивание границ, сохранение размеров, скрытие списка и увеличение чата.
- Установка приложения в меню через Ghostty/Kitty.

TUI не вызывает Anthropic API и не хранит токены. Квоты и собственную модель
показывает CLI Claude; отдельного блока лимитов в TUI нет.

## Установка и запуск

Нужны Linux, UTF-8-терминал, Rust 1.88+/Cargo и настроенный `claude` в PATH.
Для заметок/просмотра нужен `nvim`; для запускателя — Bash и Python 3.
Для меню приложения нужен Ghostty или Kitty. Nerd Font улучшает отображение иконок.

```sh
git clone https://github.com/andrey-losikhin/claude-code-tui.git
cd claude-code-tui
cargo build --release --locked
./target/release/claude-code-tui
```

```sh
./install.sh                     # собрать и добавить Claude Code TUI в меню
./install.sh --terminal kitty    # явно выбрать терминал
./install.sh --no-build          # установить готовый release
```

Установка пишет бинарник и запускатель в `~/.local/bin`, ярлык — в XDG applications.
Открытие приложения не вызывает Cargo. После обновления исходников повторите
установку и перезапустите окно. Конфиги Claude, Neovim и терминала не меняются.
При первой сборке зависимости скачиваются. Для работы с заполненным кэшем
без сети используйте `CARGO_NET_OFFLINE=true`.

В разработке: `./run.sh --terminal here`, `--terminal ghostty` или `--terminal kitty`.

## Управление

| Сочетание | Действие |
| --- | --- |
| `Alt+1 / 2 / 3 / 4` | Проекты / диалог / открытые сессии / заметка (создать или показать) |
| `Alt+стрелки` | Переход по расположению панелей |
| `Alt+N` / `Alt+Т` | Новый чат с выбором каталога |
| `Alt+O` / `Alt+Щ` | Менеджер именованных рабочих сессий |
| `Alt+S` / `Alt+Ы` | Fuzzy переключатель открытых и недавних чатов |
| `Alt+J` / `Alt+О` | Предыдущий чат |
| `Alt+K` / `Alt+Л` | Палитра команд с поиском |
| `Alt+H` / `Alt+Р` | Окно со всеми сочетаниями TUI |
| `Alt+Z` / `Alt+Я` | Свернуть все проекты |
| `Alt+F` / `Alt+А` | Поиск сообщений и Markdown заметок |
| `Alt+L` / `Alt+Д` | Каталог заметок базы знаний |
| `Alt+E` / `Alt+У` | Выделение панели Claude в текущую заметку |
| `Alt+U` / `Alt+Г` | Скрыть/показать боковую панель |
| `Alt+D` / `Alt+В` | Увеличить/восстановить чат |
| `Alt+T` / `Alt+Е` | Desktop уведомления (по умолчанию выключены) |
| `Alt+A` / `Alt+Ф` | Звук уведомлений (по умолчанию выключен) |
| `Alt+X` / `Alt+Ч` | Закрыть только текущий Claude и вернуться к проектам |
| `Alt+M` / `Alt+Ь` | Создать, показать или скрыть заметку |
| `Alt+B` / `Alt+И` | Просмотр только вывода текущего чата в Neovim |
| `Alt+V` / `Alt+М` | То же, если терминал пропускает клавишу |
| `Alt+C` / `Alt+С` | Выделение TUI либо передача перетаскивания CLI/nvim |
| `Alt+Q` / `Alt+Й` | Выход с подтверждением несохранённых заметок в nvim |
| `↑/↓`, `←/→`, `Enter` | Выбор, сворачивание/разворачивание, открытие чата |
| `/` или `f`, `r`, `p`, `m` | Поиск, переименование, закрепление, override модели |
| `r` в открытых сессиях | Переименование выбранного открытого чата |
| `?` в списке | Справка |

В окнах: ввод фильтрует, ↑/↓ выбирают, Enter или клик открывает, Esc закрывает.
Глобальные сочетания доступны и внутри окон. Перетаскивайте вертикальную границу
списка и горизонтальные границы проектов/открытых чатов и чата/заметки;
пропорции сохраняются. В заголовках панелей указаны номера 1…4; переключение — Alt с номером.

### Рабочие сессии

Alt+O открывает менеджер из Claude, Neovim или списка. Сохраняются набор открытых
чатов, активный чат, видимые заметки, выбранная модель и размеры/состояние панелей.
Выберите имя для открытия, переименования или удаления снимка. Можно обновить
текущий снимок, сохранить и закрыть чаты либо закрыть без обновления снимка.
Закрытие и восстановление требуют подтверждения: работающие задачи CLI будут
остановлены. Несохранённые заметки проходят диалог Neovim сохранить/отбросить/
отменить; Alt+стрелки отменяют ожидающее закрытие. При восстановлении процессы
CLI запускаются заново с UUID и историей: выполняющаяся задача и неотправленный
ввод не восстанавливаются. Чат без сохранённой истории запускается с прежним UUID.
Недоступные каталоги проверяются до закрытия текущих чатов. Ошибки запуска видны
в статусе, сохранённый снимок остаётся для повторной попытки. Удаление снимка
не удаляет истории Claude и Markdown. Снимки хранятся локально в XDG-конфиге.

Статусы получаются через добавочные command hooks CLI (`--settings`), без записи
в настройки Claude и без решений по разрешениям. Если политика отключает hooks,
статус остаётся неизвестным. ◆ означает фоновый ответ или ожидание внимания;
маркер снимается при показе чата в панели диалога. Desktop уведомления требуют
`notify-send`; звук и уведомления включаются отдельно и сохраняются в настройках.
Они не содержат текст чата. Приватный локальный socket удаляется при обычном выходе;
текст payload hooks не сохраняется и в socket не передаётся.

Поиск работает в отменяемом фоновом потоке по тексту user/assistant и сохранённым
Markdown; tool payload и записи субагентов исключены. Лимиты: 200 результатов,
5 секунд, 32 MiB на файл, 1 MiB на запись. Пропуски и ограничения видны в окне.
Результат сообщения открывает связанный чат и просмотр текста в nvim на совпадении;
результат заметки — сохранённый файл. Несохранённый текст редактора не индексируется.
Каталог открывает связанную заметку в существующем редакторе; заметки без истории
доступны для чтения. При смене чата выделение для заметки сбрасывается. Alt+E добавляет Markdown цитату в текущую заметку, сохраняя
несохранённый буфер nvim; :w сохраняет изменения.

Alt+1…4 перехватываются до Claude/nvim, включая открытые окна TUI и просмотр вывода.
Запускатели Ghostty/Kitty передают эти клавиши вместо переключения вкладок только
в окне приложения. При запуске в текущем терминале (`--terminal here`) его бинды
или оконный менеджер могут перехватить сочетание до TUI.

По умолчанию левая кнопка выделяет текст только внутри чата. При отпускании
выделение автоматически копируется через wl-copy/xclip/xsel, а при их
отсутствии — через OSC 52 (нужно разрешение терминала). Боковые панели и рамки
не попадают в копирование. Клики по спискам и колесо продолжают работать.

В заметках используются обычные `:w` и `:wq`; повторный Alt+M скрывает панель,
сохраняя редактор и буфер. В просмотре `:q` или Alt+B возвращает интерфейс.
Снимок содержит текущий экран и до 2000 строк прокрутки Claude PTY, а не полный
архив разговора. В Kitty Alt+V может быть занят плагином scrollback всего
терминала — используйте Alt+B. Терминал может перехватывать и другие клавиши.

Ctrl+C передаётся Claude и может только прервать запрос; для закрытия нужен
Alt+X. Shift+Enter и прочие модификаторы сохраняются, если терминал их сообщает.
Функциональные клавиши передаются CLI, команд TUI на них нет.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| В установленном окне старые клавиши | Повторите `./install.sh`, закройте старое окно и откройте **Claude Code TUI**. |
| Alt+1…4 переключает вкладки | Используйте ярлык или `./run.sh --terminal ghostty` / `kitty`: переопределения задаются для окна TUI. Прямой запуск наследует бинды терминала; проверьте оконный менеджер. |
| Статус чата неизвестен | Нужны command hooks Claude. Политика, отключённые hooks или несовместимый CLI могут не отправлять события. TUI не меняет политику. |
| Нет результата поиска | Читается сохранённый текст/Markdown; tools/субагенты/несохранённый буфер исключены. Ограничения и пропуски видны в окне. |
| Системный rustc падает до сборки | run/install пробуют установленный rustup stable. Нужен рабочий toolchain; скрипты не чинят системные библиотеки и не скачивают fallback скрыто. |

## Данные

- История Claude: `~/.claude/projects/**/*.jsonl` (TUI читает).
- Настройки TUI: `${XDG_CONFIG_HOME:-~/.config}/claude-code-tui/config.json`.
- Заметки: `~/knowledge-base/claude-code-tui/notes/<session-id>.md`.
- Просмотр: временный текстовый файл с правами 0600, удаляемый при закрытии.

Закрытие сессии не удаляет историю и заметку. Старые заметки из XDG data
копируются без перезаписи. При аварийном завершении может остаться временный
снимок. История, заметки и скопированный текст — личные данные: не прикладывайте
их к публичным issues. Подробности: [SECURITY.md](SECURITY.md).
