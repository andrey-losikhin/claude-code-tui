# Claude Code TUI

[English README](README.md) · [Архитектура](docs/architecture.md) · [Участие](CONTRIBUTING.md)

Локальное терминальное рабочее пространство для **Claude Code CLI**: проекты и
чаты слева, открытые сессии, диалог и Markdown-заметки в Neovim.

Проект находится в ранней разработке. Поддерживается Linux; интерфейс сейчас
на русском языке. Это независимый проект, не продукт Anthropic. Claude
запускается именно через установленный CLI с его авторизацией и разрешениями.

## Возможности

- Сворачиваемые проекты, поиск, закрепление и переименование чатов.
- Обновление названий после `/rename` во всех панелях, включая открытые сессии.
- Переключение между несколькими работающими Claude PTY без остановки других.
- Новый чат с выбором известной папки или браузером каталогов от `$HOME`.
- Заметка в Neovim под чатом; отдельный Markdown-документ в базе знаний.
- Выделение мышью построчно только внутри чата; копирование при отпускании.
- Просмотр только вывода активного Claude в Neovim.
- Палитра терминала, мышь, русские и английские клавиатурные сочетания.
- Установка приложения в меню через Ghostty/Kitty.

TUI не вызывает Anthropic API и не хранит токены. Квоты и собственную модель
показывает CLI Claude; отдельного блока лимитов в TUI нет.

## Установка и запуск

Нужны Linux, UTF-8-терминал, Rust 1.88+/Cargo и настроенный `claude` в PATH.
Для заметок/просмотра нужен `nvim`; для запускателя — Bash и Python 3.
Для меню приложения нужен Ghostty или Kitty. Nerd Font улучшает отображение иконок.

```sh
git clone https://github.com/andrey-losikhin/claude-code-tui.git
cd claude-code-tui
cargo build --release --locked
./target/release/claude-code-tui
```

```sh
./install.sh                     # собрать и добавить Claude Code TUI в меню
./install.sh --terminal kitty    # явно выбрать терминал
./install.sh --no-build          # установить готовый release
```

Установка пишет бинарник и запускатель в `~/.local/bin`, ярлык — в XDG applications.
Открытие приложения не вызывает Cargo. После обновления исходников повторите
установку и перезапустите окно. Конфиги Claude, Neovim и терминала не меняются.
При первой сборке зависимости скачиваются. Для работы с заполненным кэшем
без сети используйте `CARGO_NET_OFFLINE=true`.

В разработке: `./run.sh --terminal here`, `--terminal ghostty` или `--terminal kitty`.

## Управление

| Сочетание | Действие |
| --- | --- |
| `Alt+стрелки` | Переход по расположению панелей |
| `Alt+N` / `Alt+Т` | Новый чат с выбором каталога |
| `Alt+X` / `Alt+Ч` | Закрыть только текущий Claude и вернуться к проектам |
| `Alt+M` / `Alt+Ь` | Создать, показать или скрыть заметку |
| `Alt+B` / `Alt+И` | Просмотр только вывода текущего чата в Neovim |
| `Alt+V` / `Alt+М` | То же, если терминал пропускает клавишу |
| `Alt+C` / `Alt+С` | Выделение TUI либо передача перетаскивания CLI/nvim |
| `Alt+Q` / `Alt+Й` | Выход с подтверждением несохранённых заметок в nvim |
| `↑/↓`, `←/→`, `Enter` | Выбор, сворачивание/разворачивание, открытие чата |
| `/` или `f`, `r`, `p`, `m` | Поиск, переименование, закрепление, override модели |
| `r` в открытых сессиях | Переименование выбранного открытого чата |
| `?` в списке | Справка |

По умолчанию левая кнопка выделяет текст только внутри чата. При отпускании
выделение автоматически копируется через wl-copy/xclip/xsel, а при их
отсутствии — через OSC 52 (нужно разрешение терминала). Боковые панели и рамки
не попадают в копирование. Клики по спискам и колесо продолжают работать.

В заметках используются обычные `:w` и `:wq`; повторный Alt+M скрывает панель,
сохраняя редактор и буфер. В просмотре `:q` или Alt+B возвращает интерфейс.
Снимок содержит текущий экран и до 2000 строк прокрутки Claude PTY, а не полный
архив разговора. В Kitty Alt+V может быть занят плагином scrollback всего
терминала — используйте Alt+B. Терминал может перехватывать и другие клавиши.

Ctrl+C передаётся Claude и может только прервать запрос; для закрытия нужен
Alt+X. Shift+Enter и прочие модификаторы сохраняются, если терминал их сообщает.
Функциональные клавиши передаются CLI, команд TUI на них нет.

## Данные

- История Claude: `~/.claude/projects/**/*.jsonl` (TUI читает).
- Настройки TUI: `${XDG_CONFIG_HOME:-~/.config}/claude-code-tui/config.json`.
- Заметки: `~/knowledge-base/claude-code-tui/notes/<session-id>.md`.
- Просмотр: временный текстовый файл с правами 0600, удаляемый при закрытии.

Закрытие сессии не удаляет историю и заметку. Старые заметки из XDG data
копируются без перезаписи. При аварийном завершении может остаться временный
снимок. История, заметки и скопированный текст — личные данные: не прикладывайте
их к публичным issues. Подробности: [SECURITY.md](SECURITY.md).
